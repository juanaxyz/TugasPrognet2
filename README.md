# 🌐 Personal Website – I Wayan Juana Satya Adinata

Website ini merupakan proyek halaman profil pribadi yang menampilkan informasi biodata, pendidikan, hobi, pengalaman organisasi, serta kontak pribadi.  
Dibangun menggunakan **HTML**, **CSS (Grid + Flexbox)**, dan sedikit **JavaScript** sederhana untuk interaksi form.

# Demo Website

https://juanaxyz.github.io/TugasPrognet2/

---

## 📋 **Fitur Utama**

✅ **Navigasi Sidebar**  
Menampilkan menu untuk berpindah antar bagian (Profile, Education, Hobbies, Organization, Contact).

✅ **Hero Section (Profile)**  
Menampilkan foto profil, deskripsi singkat, dan link sosial media.

✅ **Education History**  
Riwayat pendidikan disusun secara kronologis dalam daftar.

✅ **Hobbies Section**  
Berisi daftar hobi dengan tampilan rapi dan ringan.

✅ **Organization Experience**  
Ditampilkan dalam tabel yang responsif dan mudah dibaca.

✅ **Contact Form + WhatsApp Link**  
Formulir sederhana untuk mengirim pesan, dan tombol cepat ke WhatsApp.
